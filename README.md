# Open Course Space Courses – Moved to Docsify-This

> The example courses of the free [Grav Open Course Space](https://github.com/hibbitts-design/grav-skeleton-open-course-space) site, moved to [Docsify-This](https://docsify-this.net/#/) as plain Markdown pages by the [Grav Docsify Bridge](https://grav-docsify-bridge.hibbittsdesign.org).

View it as a website: https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-open-course-space-courses-site/main&homepage=home.md&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&pagination=true&searchbox=true&collapsibleSidebarGroups=true&dark-mode=auto&name=Open%20Course%20Space%20Courses

These pages are the bridge's output as it is, shown like the site in Open Course Space: the home page is the Courses page, with a card for each course, and each course has its own home page, Modules page, sidebar of modules and navbar of menu pages.

The Grav version is at https://demo.hibbittsdesign.org/grav-open-course-space/courses – this version uses the same content:

- `home.md` – the Courses page
- `cpt363-basic/` – CPT363-1, a basic course organised by modules
- `cpt363-intermediate/` – CPT363-2, with more page types and features
- `cpt363-advanced/` – CPT363-3, with the most page types and features

Only the courses are moved – the Grav site's other pages, such as its blog and About the Courses page, stay there, and links to them go to the Grav site.

The pages are clean Markdown, without the bridge's hidden notes. The bridge can still turn them into Open Course Space courses, like any Docsify site, but not exactly.
